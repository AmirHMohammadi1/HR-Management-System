# سیستم مدیریت منابع انسانی

یک سیستم جامع برای مدیریت منابع انسانی با قابلیت‌های زیر:

## ویژگی‌ها

- مدیریت اطلاعات کارمندان
- مدیریت فرآیند استخدام
- ردیابی حضور و غیاب
- مدیریت حقوق و دستمزد
- ارزیابی عملکرد
- پشتیبانی از دو زبان فارسی و انگلیسی
- طراحی ریسپانسیو

## تکنولوژی‌ها

- Next.js 15 با App Router
- TypeScript
- Tailwind CSS 4
- React Hooks

## نصب و راه‌اندازی

1. کلون کردن پروژه
2. نصب dependencies: `npm install`
3. کپی کردن فایل env: `cp .env.example .env.local`
4. پر کردن مقادیر محیطی
5. اجرای پروژه: `npm run dev`
